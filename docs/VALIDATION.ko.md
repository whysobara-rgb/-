## 완료한 코드 변경

- 모의 소셜 로그인과 임의 providerId 제출 경로 제거.
- GP 충전 API 호출·결제 시뮬레이션 제거. 결과 화면의 87% 로컬 GP 지급 및 재뽑기 로컬 차감 제거. GpProvider를 서버 잔액 표시 전용으로 축소.
- API 주소를 HTTPS 빌드 설정으로 분리. 응답 제한시간·HTTP/업무 오류 구분·JSON 오류 처리·변경 요청 자동 재전송 금지.
- 토큰을 flutter_secure_storage 9.2.4로 이동. 기존 평문 토큰은 제거 후 재로그인. 저장소 실패 시 초기 로딩 종료, 일시 서버 장애 시 자격증명 유지.
- 정책과 불일치하는 기존 즉시 개봉/고정 배송비 요청은 출시 빌드 차단. debug/profile도 명시적 설정 전 기본 차단. 서버 차단을 대체하지 않음.
- 판매 잔여 재고에 맞춘 MAX, 구매 확인 중 중복 진입 방지.
- 뽑기 오류 시 대기 화면 종료, 실거래 중 디버그 연출로 결과를 덮어쓰거나 재추첨하던 경로 제거. 응답 개수 검증.
- 결과 강조는 프리미엄 우선·소비자가 높은 순. 전환 GP와 프리미엄 구분은 서버 값만 사용; 전환액 누락 시 견적 확인 필요 표시.
- 알 수 없는 보관함 상태는 배송/전환 불가. 잠금은 전환만 제한. 배송 대상 상태·중복·전화 검증, 우편번호 전달 보완.
- GP 화면의 오류/빈 상태 분리, 탭 이름·접근성 라벨, Android INTERNET·HTTPS·백업 설정.
- 회귀 테스트와 Flutter CI 추가. 출시 설계·거래 API 계약·실행 가이드 작성.

Flutter 3.35.4 소스를 확보하고 SDK 초기화를 시도했으나, 초기화 중 클라우드 메타데이터 주소(169.254.169.254)에 대한 접근이 발생해 자동 승인 검토가 실행을 거절했다. 민감한 인스턴스 정보·자격증명 접근 위험이 이유다. 해당 접근을 우회하지 않았다. 별도의 로컬 Dart formatter는 실행됐다.

새 flutter_secure_storage 의존성의 **pubspec.lock 갱신은 아직 완료하지 못했다.** 승인된 개발 환경에서 `flutter pub get`을 실행해 잠금파일을 생성·검토·커밋한 뒤 analyze/test를 통과시켜야 한다. 현재 CI는 의존성 해결 후 분석·테스트를 실행하도록 작성되어 있으며 이 대화에서 CI 통과를 확인하지 않았다. 잠금파일이 확정되면 CI에서 `flutter pub get --enforce-lockfile`로 강화한다.

## 작성한 회귀 테스트

- 자동 로그인: 일시 장애와 만료 인증 구분, 저장소 오류 시 로딩 종료.
- 보관함: 잠금과 배송 조건 분리, 미지원/배송 완료 상태의 변경 차단.
- 뽑기 결과: 임의 전환율·프리미엄 추론 금지, 서버 GP 스냅샷 표시, 소비자가 우선 연출.
- 로그인 위젯: 모의 소셜 버튼 제거, 입력 없는 로그인 차단.
