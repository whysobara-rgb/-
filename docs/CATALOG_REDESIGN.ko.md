# 홈·박스 상세 개편 1차

기존 서버 구매·개봉 복구 흐름에 연결된 Flutter 화면을 개편한다.

- 중립 배경·명확한 본문 대비·코랄 포인트, 공통 입력창/버튼/선택 칩 적용
- 홈: 실제 로드된 박스 이름 검색과 가격 정렬, 카탈로그 기반 대표 박스, 기능 없는 알림/퀵메뉴 제거
- 카드: 실제 badgeLabel 그대로 표시(TEST를 HOT으로 바꾸지 않음), 이미지 누락 시 상품 아이콘, 긴 제목과 큰 글씨 지원
- 상세: 제목·단가·잔여 수량·실제 서버 PPM 확률 안내, 확률 조회 실패 시 미확인 상태 명시
- 구매 수량은 서버 1회 최대 100개 및 남은 수량과 일치, 품절 버튼 비활성화
- 하단 내비게이션은 일관된 아이콘·텍스트 레이블 사용

## 검증

catalog_redesign_test.dart는 실제 CatalogScreen 및 ProductDetailView 위젯을 사용한다. 홈 검색·정렬, 상세 확률 표시·확인 버튼, 320px/큰 글씨 레이아웃을 확인한다. build/ui-previews의 PNG는 Flutter가 렌더링한 화면이다. 상품명·금액·수량은 미리보기 전용 합성 데이터이며 API에 전송되지 않는다. 이미지 목업이 아니라 앱 위젯의 렌더링이지만 실제 iOS 기기 검증을 대체하지 않는다.

## 범위

홈·상세·공통 디자인 1차 구현. 지갑·보관함·개봉 연출 등 나머지 화면은 후속 개편이다. 카탈로그 검색은 현재 로드된 목록에 적용한다. 구매 전 OrderFlowPage에서 최신 가격·확률을 다시 조회하고 동의를 받는다. 실제 주문·원장 코드는 변경하지 않는다.
