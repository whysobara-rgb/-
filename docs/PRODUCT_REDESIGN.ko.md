# 가치가차 제품 완성도 개편

2026-09-14 사용자 방향 변경: 사용자 수동 네트워크 검증을 보류하고 전체 기능과 내부 UI 완성도를 우선한다. 사용자는 iPhone을 사용하므로 APK 설치를 디자인 검토의 전제로 삼지 않는다. 이 문서는 구현 계획이며, 화면 개편 완료를 의미하지 않는다.

## 제품 방향

상품을 발견하고, 공개된 조건과 확률을 확인하고, 획득한 상품을 수집·관리하는 일관된 경험을 만든다. 티프의 공개 소개에 나타난 탐색·컬렉션·실물 수령 흐름을 참고한다. 사용자간 거래·경매·교환은 신규 사업 정책과 별도 서버 기능이 필요한 확장 범위이며 첫 출시의 필수 기능으로 자동 추가하지 않는다.
참고: https://play.google.com/store/apps/details?id=kr.tif.app&hl=ko

## 디자인 기준

- 기존 코랄을 브랜드 포인트로 유지하고 밝은 중립 배경, 짙은 본문색, 절제된 강조색을 사용한다.
- Pretendard 타이포그래피, 간격, 모서리, 버튼, 상품 카드, 하단 시트, 상태 안내를 공통 컴포넌트로 통일한다.
- 상품 이미지가 중심이 되도록 배너와 장식을 제한한다. 개봉 순간에 애니메이션을 집중하고 건너뛰기·동작 줄이기를 지원한다.
- 모바일 좁은 화면·큰 글씨·키보드·안전 영역에서 내용과 주요 버튼이 가려지지 않게 한다.
- 로딩·빈 목록·품절·통신 실패·로그인 만료·잔액 부족·복구 중 상태를 완성된 화면의 일부로 취급한다.
- 미구현 기능 버튼과 가상 판매량·가짜 실시간 당첨을 운영 화면에 배치하지 않는다. 디자인 예시 데이터는 미리보기 전용이며 실제 거래 데이터와 분리한다.

## 개발 순서와 산출물

| 순서 | 범위 | 완료 기준 |
|---|---|---|
| 1 | 전체 화면 구성 및 공통 디자인 | 색상·글자·간격·버튼·카드 규칙, 화면 목록과 이동 경로 정리 |
| 2 | 홈·상품 탐색·박스 상세 | 탐색/분류, 명확한 가격·상품·확률·재고·구매 행동, 주요 화면 미리보기 |
| 3 | 구매·미개봉·개봉 결과·보관함 | 단계가 끊기지 않는 흐름, 보관함 선택·잠금·상세, 결과 연출과 명확한 다음 행동 |
| 4 | 지갑·내역·배송·프로필·고객지원 | 실제 서버 연동 가능 범위 완성, 결제/배송/본인인증 등 미연동 의존성 명시 |
| 5 | 통합 검증·출시 준비 | Android/iOS 실제 앱, 결제·환불·배송, 통신 중단·중복 요청 검증 |

## 검증 책임과 검토 방식

자동 빌드·정적 분석과 금액·상품 지급에 관한 회귀 검사는 개발 중 계속 수행한다. 사용자에게 반복적인 수동 테스트를 요구하지 않는다. 화면 단위 이미지와 가능한 경우 iPhone 브라우저용 탐색 미리보기를 제공한다. 브라우저 미리보기는 native iOS 설치본 검증을 대체하지 않는다. 최종 기기·통신 중단 인수 검증은 주요 기능과 UI 통합 후 진행한다.

## 현재 상태

서버 구매·개봉 및 테스트 GP 기반 사용자 정상 흐름 확인 완료. 자동 테스트와 구분해, 실제 단말의 통신 중단 시나리오는 아직 미완료다. 이번 변경은 제품 개편 방향과 작업 범위를 저장한 단계다. 실행 환경 연결 오류가 있는 동안에는 GitHub 소스 검토·설계 정리를 진행하며 실제 렌더링이나 새 UI 빌드를 완료했다고 보고하지 않는다.
