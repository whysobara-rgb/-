# 네이티브 일괄 개봉 · 2026-09-15

앱 PR #1의 최신 검증 기반에 최대 100개 일괄 개봉을 추가했다. 웹 v19 영상은 변경하지 않았다. 이번 네이티브 변경에 최신 웹 화면 전체나 v19 영상이 이식된 것은 아니다.

- 미개봉 보관함에서 페이지를 넘겨 최대 100개 선택, 개수·추가 결제 0 GP·개봉 후 상태 변경 확인 후 시작.
- 각 캡슐 ID를 서버의 기존 멱등 개봉 API로 처리하고, 다음 캡슐 전에 확정 결과를 보안 저장소에 저장.
- 종료·응답 유실·저장 실패 뒤에는 미확정 캡슐의 결과를 GET으로 먼저 확인. 명시적인 미개봉 응답만 같은 캡슐 재요청을 허용.
- 화면 이탈·백그라운드·사용자 멈춤은 현재 요청까지만 처리. 아직 보내지 않은 캡슐은 미개봉 상태로 남음.
- 계정·서버별 큐 분리. 단일 개봉·중복 일괄 작업은 같은 계정의 복구 기록을 먼저 확인.
- 결과 전체/등급 필터, 동일 상품 묶음 수량 표시. 확정 상품은 서버 보관함에도 저장됨.
- 확정한 부분 결과를 확인하고 작업을 종료할 수 있음. 미확정 요청이 남아 있으면 복구 기록을 지울 수 없음.

구현은 기존 테스트 거래 설정을 유지한다. 운영 결제를 활성화하거나 DB/Render를 변경하지 않는다.

검증 대상: 신규 11개 검사(100개 처리, 재시작, 저장 실패, 불명확 응답, 미개봉 재시도, 중단, 동시 요청, 계정 분리, 잘못된 결과, 선택·동의·그룹 화면, 현재 요청 후 멈춤)를 추가했다. 로컬 Flutter 도구의 의존성 준비는 환경 메타데이터 주소 접근으로 자동 승인 검토에서 차단됐다. 로컬 실행 성공으로 집계하지 않으며, GitHub의 기존 Flutter 분석·테스트/Android/iOS 워크플로 결과를 이 커밋 기준으로 확인해야 한다.

GP 전환/복구 연결은 NATIVE_GP_CONVERSION.ko.md의 후속 변경을 따른다.

남은 네이티브 작업: 최신 홈·상품 UI, 배송 견적·신청·취소, 카드 결제·환불·내역, 계정/문의/알림, 최신 구슬 연출 통합과 실기기 검수. 서버 PR #3의 운영 반영과 실결제·정책·스토어 검수도 별도다.
