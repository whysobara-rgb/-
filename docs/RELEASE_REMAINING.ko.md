# 출시 완료 판정과 남은 작업

현재 상태: 개발 브랜치에서 UI와 거래 기반을 구현 중. 출시 완료가 아님.

## 구현한 범위
- 서버 상품 검색·정렬·상세·확률 표시
- GP 테스트 구매·개봉 및 응답 유실 복구
- 서버 확정 결과의 짧은 공개 연출, 건너뛰기, 동작 줄이기
- 컬렉션 카드, 확대 상세, 상태 필터, 잠금
- 프로필·GP 지갑·포인트 내역 연결

## 우선순위
1. 컬렉션 전체 페이지 조회와 화면별 실제 데이터 검증
2. 최신 전체 화면 캡처: 홈, 상세, 구매, 결과, 보관함, 마이, 지갑
3. 제품 이미지·한글·접근성·여백·CTA 배치 시각 검수
4. 배송 요청/내역/실패 복구와 운영 배송비 정책 연결
5. 전환 GP 정책 및 중복 방지 원장 구현
6. 실제 결제 사업자 연동, 검증 webhook, 취소/환불
7. 문의·공지·약관·개인정보·회원탈퇴 운영 기능
8. iOS 빌드/서명 및 양 플랫폼 실기기 회귀 검증
9. 운영 설정, 모니터링, 백업, 스토어 제출

## 완료 기준
테스트 통과는 시각적 완성도 또는 출시 승인을 뜻하지 않는다.
삭제한 미지원 메뉴는 구현 완료 항목으로 집계하지 않는다.
현재 연출은 상품 결과 공개이며 전체 캡슐 개봉 시퀀스 완성은 아니다.
개발 PR 반영은 main 병합이나 운영 배포를 뜻하지 않는다.
실제 결제와 배송 활성화는 사업자 설정 및 확정 정책이 필요하다.
