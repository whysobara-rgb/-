# 2026-09-15 후속 진행

최신 네이티브 코드에 최대 100개 일괄 개봉·중단 복구와 GP 전환/복구·전환 내역을 추가했다. NATIVE_BATCH_OPENING.ko.md 및 NATIVE_GP_CONVERSION.ko.md를 기준으로 해당 기능의 현재 범위를 확인한다. 아래 표는 9월 14일 시점의 기록이며 신규 커밋의 CI와 실제 운영 반영은 구분한다.

웹·서버 기능 묶음 20개는 완료 14 / 부분 5 / 미구현 1로 갱신한다. 네이티브 반영을 미구현에서 부분 구현으로 변경했으며, 전체 20개의 공수나 출시 가능 비율을 뜻하지 않는다. 출시 관문 7개 중 운영 반영·실결제·정책·최종 네이티브 빌드·실기기·스토어 6개는 여전히 남아 있다.

검사 대상은 각 실행의 커밋으로 식별합니다. UI 캡처는 실제 Flutter 화면을 합성 테스트 데이터로 렌더링한 것입니다. 상용 상품 구성 또는 실제 고객 거래의 증거가 아닙니다.
Android 네이티브 검사는 실제 앱 설치·시작과 별도 보안 저장소 검증 앱의 강제 종료 후 복구를 구분합니다. 복구 검사에서는 실제 PG 결제를 호출하지 않습니다.
iOS는 시뮬레이터 빌드·설치·첫 프레임·Keychain 재시작 복구를 검사합니다. 해당 실행의 성공 여부는 CI 기록에서 확인합니다. 실제 iPhone 설치와 TestFlight 배포는 별도입니다.
BlueStacks 설치 오류는 구체적 설치 실패 코드가 없어 원인 확정/해결 판정을 하지 않았습니다.

- [ ] 실제 판매 상품·소비자가 근거·이미지 사용 권한과 공급 재고
