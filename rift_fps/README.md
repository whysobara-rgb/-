# RIFT BREAKER — 차원의 틈 FPS

괴생물체가 쏟아지는 차원의 틈에 들어간 엘리트 군인이 되는 싱글플레이 웹 FPS (Three.js).

## 실행
```bash
cd rift_fps
npm start            # http://localhost:8080
```
외부 의존성 없음 (Three.js r160은 `public/vendor`에 포함).

## 세이브 분리
- 로그인 시 **서버(ALPHA/BRAVO/CHARLIE/DELTA) + 콜사인 + PIN** 을 입력합니다.
- 세이브는 `saves/<서버>/<콜사인 해시>.json` 에 플레이어마다 별도 파일로 저장되므로 다른 사람·다른 서버와 겹치지 않습니다.
  쓰기는 파일별로 직렬화되고 임시 파일→rename 으로 원자적으로 교체됩니다.
- Node 서버 없이 정적 호스팅으로 열면 브라우저 저장소에 `서버::콜사인` 키로 분리 저장됩니다.

## 게임 시스템
- **무기 120종**: 20계열(권총·기관단총·돌격소총·점사·더블 라이플·샷건·더블 샷건·관통 저격총·레일건·폭발 소총·관통폭발 캐논·RPG·수류탄·유탄·미니건·레이저·플라즈마·테슬라 연쇄·플랙·크라이오) × 6등급(일반~신화). 등급·계열마다 3D 모델, 카드 UI, 피해/연사/장전/탄창이 모두 다름.
- **차원의 틈**: 한 판에 300~5000 개체 랜덤. 제한 시간(약 1분 40초~4분)이 지나면 균열이 붕괴해 남은 개체가 소멸하고 보스가 강림. 괴물이 포탈에서 나와 플레이어를 향해 돌진. 진행 33%/66%에 중간보스, 마지막에 보스(지면 강타·돌진·탄막·소환·격노 패턴).
- **드랍**: 일반 처치 시 무기 6%, 중간보스 45%, 보스 100%(+추가 드랍). 보스급은 코인·고등급 확률도 상승.
- **상점**: 매일 5종 무기(날짜·서버·플레이어 시드), 방어구 7종.
- **랜덤 뽑기**: 클리어할 때마다 배너 가격·등급 확률·픽업 계열이 바뀜. 1회/10회.
- **사망 페널티**: 보유 아이템(무기·방어구) 중 20~40% 랜덤 소실. 무기는 1개 아래로 떨어지지 않음.
- **근접 무기 9계열 × 6등급 (54종)**: 컴뱃 나이프·카타나·대검·전쟁 망치(지면 충격파)·체인소드·차원 낫(360° 베기)·플라즈마 블레이드(검기 발사)·파워 건틀릿(폭발 타격)·에너지 창(관통 찌르기). 탄약 없음, 적중 시 체력 흡수. 신규 요원은 컴뱃 나이프를 기본 지급.
- **비행 괴물**: 공허 박쥐(상공에서 급강하 후 재상승), 부유 감시자(공중에서 거리 유지하며 사격). 보스도 박쥐를 소환.
- **타격감**: 스프링 반동(되튐)·조준점 상승·좌우 흔들림·FOV 펀치·탄피 배출·히트스톱·피격 펄스/넉백·처치 연출·콤보 따라 높아지는 처치음·계열별 총성.
- **스킬**: Q 대시(무적), E 충격파, F 오버드라이브, G 수류탄, V 근접 베기.
