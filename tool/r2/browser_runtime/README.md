# 가치가차 R2-A1 실제 Flutter 브라우저 검토

1. ZIP을 모두 압축 해제합니다. `index.html`을 직접 열지 마세요.
2. Windows: `Start-Preview.cmd`를 더블 클릭합니다. PowerShell 창을 열어 둡니다.
3. 브라우저에서 **http://127.0.0.1:8765** 를 엽니다. 창을 닫거나 Ctrl+C를 누르면 종료됩니다.
4. Python 3가 설치된 PC/Mac/Linux에서는 대신 이 폴더에서 `python3 serve.py`를 실행해도 됩니다. Windows Python은 `py serve.py`입니다.

공개 URL이 아닙니다. 실행한 **동일 PC**에서만 접속합니다. 휴대전화에서 PC의 localhost를 열 수 없습니다.
포트가 이미 사용 중이면 기존 실행 창을 종료하고 다시 실행하세요. Flutter SDK나 로그인은 필요 없습니다.

화면 위의 검토 표시줄에서 화면, 100%/200% 글자, 샘플 사진을 선택합니다.
실제 앱 영역 안에서 홈 스크롤 → 구성·확률 보기 → 상세 → 구매 확인 → 확률 안내를 조작할 수 있습니다.
박스샵에서 검색과 필터 적용/닫기를 사용할 수 있습니다. 이전 화면은 앱 뒤로가기 또는 위 표시줄을 이용합니다.

미개봉 선택은 실제 위젯이며 최종 실행은 차단됩니다. 개봉 연출/단일·다중·부분 결과/보관함은 **서버 거래로 생성되지 않은 고정 샘플**입니다.
연출 진입 시 2초 뒤 정해진 샘플이 표시됩니다. Skip은 기존 표현 위젯의 동작입니다.
구매·개봉·배송·환불·전환·계정 기능을 실제로 실행하지 않습니다. 랭킹/지갑/소식/마이 등 연결하지 않은 버튼은 표시줄에 범위 밖으로 안내합니다.

홈/샵은 R2-A1, 상세/구매/개봉/결과/보관함은 기존 구현입니다. R2-B/C/D, 실서버 연결, 상품 사진 매칭, 실기기 인수는 미완료입니다.
합성 GP/가격/확률/재고/구성/보관함은 검토 데이터입니다. 홈 사진은 허용된 Unsplash 편집 샘플이며 실제 당첨 상품을 뜻하지 않습니다. 출처는 `PHOTO-RIGHTS.md`를 참고하세요.

보안: API_BASE_URL 없이 컴파일, 실제 기능 gate OFF, MockClient 읽기만 제공, 모든 변경 요청 거절, loopback 정적 서버 및 외부 연결 차단 CSP.
실제 계정·비밀번호·토큰·사용자 데이터를 포함하지 않습니다. 이 패키지는 공개 서비스·native 앱 배포가 아닙니다.
