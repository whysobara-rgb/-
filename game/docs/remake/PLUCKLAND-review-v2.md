## v2.1에서 바뀐 핵심

- **재미의 중심 이동**: 처음 한 번은 개그 장면(도감 카드), 그 뒤로는 매번 작동하는 **시스템 규칙 10개**(주인은 뽑힌 자기 물건을 따라옴, 동물은 열에 모임, 주민은 시간대별 빛·그늘에 모임 등). 구역마다 **부탁 보드**(그림 카드 3장, 카드마다 해법 2개 이상, 아무 2장이면 통과).
- **당기기 재설계**: 아날로그 트리거 깊이 = 당기는 힘. 반쯤 눌러 텐션을 "초록 띠"에 붙잡는 게 실력. 점수 = 훅 30 + 초록 띠 비율 70. 결과(크기 기록, 윤기 변종, 착지 방향)가 실력에서 나옴. 숨은 보정 대신 보이는 보조 옵션 하나. 같은 종류를 익히면 즉시 뽑기.
- **조작 계약**: "행동 버튼 2개 + 스틱". 들기는 래치, 길게 눌렀다 떼면 던지기(착지 표시), 놓는 방향은 바라보는 방향 + LB/RB 90° 회전, 잡기 대상 규칙(정면 칸 → 45° 원뿔) + 현재 대상 표시.
- **성장 축 정리**: 손힘 단계 0~5(S=0, M=1, L=2, XL=4), 1단계는 0장 배나무 줄 서기 보상, 도깨비 풀어 주기는 손힘 제한 면제.
- **뿌리 문법**: "영원히 안 뽑히는 건 없다" + 읽히는 잠금 4종(손힘·말뚝·도깨비 눈·무지개 줄 서기) + "붙박이 장식" 분류.
- **밀도**: 챕터마다 하위 기믹 3개, 10~15분 구역마다 소개→응용→비틀기→졸업, 새 요소 간격 최대 5분(실측표 1.1~4.2분).
- **세계·기술**: 1m 격자 + 0.5m 높이 + 층(덱)·포털, 텍스트 레벨 + 자동 미리보기 + 풀이 봇, 정해진 결과로 움직이는 퍼즐 물리, 조용한 순간에만 저장.
- **범위**: 0장 + 1장(무게) + 2장(바람) + 3장(열·물·증기, v1 3·4장 합본) + 4장(말뚝도시, v1 5장) + 최종장. 메인 약 4.4시간, 전체 약 7시간. 곁들이 66→48개로 줄임.
- **시장**: "가족이 탄 채로 집째 뽑아 이사 가기"를 앞세움(바난자 비교는 내부용), 홍보 영상 당기기 장면 1초 이하, $14.99, 한·영·일·중 출시, 위시리스트 관문(넥스트 페스트 전 7천 → 이후 1.5~2만 → 12개월 차 2.5만(1.5만 미만이면 축소) → 출시 4~6만).
- **문서 구조**: 26장 + 설계 결정 기록(D-01~D-26) + 부록 A·B·C, 약 2,100줄.

## 최종 평가 (최종 채점자, 원문 그대로)

> v2.1은 v1 평가의 치명 문제를 모두 정면으로 고쳤습니다. 재미의 중심을 당기기에서 '옮긴 결과'로 옮겼고(시스템 규칙 10개, 구역마다 3장 중 2장을 고르는 부탁 보드), 당기기에는 숨은 보정 대신 텐션을 초록 띠에 붙잡는 실력 층을 넣었습니다. 손힘 단계와 동사 점검표, 잠금 4종, 6×6 조합표, 격자·덱 세계 모델, 텍스트 레벨과 풀이 봇, 축소 순서까지 정리해서 1인+에이전트 인디 기획서로는 드물게 단단합니다. 그래서 네 관점 모두 v1(6 / 5.5 / 5.5 / 5)보다 1~2.5점 올랐습니다. 다만 이 점수는 아직 종이 위의 점수입니다. 당기기 손맛과 '결과가 재미'라는 핵심 가설은 한 번도 플레이로 확인되지 않았습니다. 4.4시간짜리 아늑한 게임치고 규칙·속성·수집 층이 너무 많아 인지 부담이 걱정되고, 코드로 만든 아트가 아늑한 게임 시장의 캡슐 경쟁을 이길지도 알 수 없습니다. 상업적으로는 스팀 전용, 2028년 4월 출시, 제목 미정이라는 한계가 남아 있어서 '잘 만든 기획서, 결과는 미지수'인 7점대 초반이 정직한 평가입니다.

## 남은 위험

1. **핵심 가설 미검증**: 트리거를 반쯤 눌러 버티는 조작과 "툭" 직후 0.2초 안에 풀었다 다시 짜는 딱 걸기를 사람들이 글자 없이 찾아낼지 모름. 첫 혼자 당기기(0장 우물, 메기형)가 "계속 꾹"으로는 실패해서 처음 하는 사람에게 높은 벽이 될 수 있음.
2. **규칙 과부하**: 시스템 규칙 10 + 조합 8 + 잠금 4 + 형태 속성 9 + 칸 상태 7 + 매듭·변종·부탁·소원·마을 이벤트. 4.4시간 아늑한 게임 이용자에게 "깊이"보다 "가짓수"로 읽힐 위험. 세부 예외 규칙이 다시 "왜 이건 안 돼?"를 만들 수 있음.
3. **아트 경쟁력**: 아늑한 게임은 캡슐·첫 GIF가 위시리스트를 좌우하는데, 코드로 만든 아트가 A Short Hike·Tinykin급 캡슐 옆에서 이길지 검증 계획이 약함.
4. **주인공 호소력 미확정**: 6주 차 A/B에서 바뀌면 리그·아트·문구 재작업.
5. **일정**: 수직 슬라이스 10주에 너무 많이 들어감. 오너 주 20~23시간과 처음 하는 테스터 약 100명이 실제 병목. 축소 없이 2028년 4월 출시 확률 30% 안팎.
6. **상업적 한계**: 스팀 전용, 19개월 뒤 출시, 영문 제목 미정.
7. **작은 모순 6개**: 한 번뿐인 L·XL을 "보통"으로 뽑으면 윤기 변종 영구 누락, 동행 6명 고르는 규칙, 사람 다리 깃발 배치, 2-1 "스위치" 정의, 허수아비 등급, 등대 높이.
8. **문서 자체의 무게**: 프로토타입 전인데 수치가 너무 촘촘함 → 손맛 검증에서 숫자가 바뀌면 연쇄 수정, 에이전트가 낡은 수치를 따를 위험.
9. **참고 영상 미반영**.

## 추천 다음 단계

1. **3주 손맛 검증을 바로 시작**. 관문 2개(시키지 않은 잡기, 실패를 "내가 못했다"로 느끼는지) + 텔레메트리 3개(딱 걸기를 스스로 찾는 비율, 초록 띠 체류 분포, 0장 우물 첫 시도 미끄러짐률). 못 넘으면 당기기를 단순화(첫 혼자 당기기를 잉어형으로, 딱 걸기를 "툭에 누르기"로).
2. **4~6주 차 "아트 기준선 시험"**: 최종 품질 디오라마 방 1개 + 옹이 캡슐 시안을 실제 아늑한 게임 캡슐 10개 옆에 놓고 클릭 의향·기억률 측정. 기준 미달이면 캡슐·키아트만이라도 외주 예산.
3. **수직 슬라이스를 두 단계로**: 1단계 0장 + 1-1·1-2 + 행렬 1회 + 마을 다시 심기 + 저장 / 2단계 도깨비·NPC 규칙 엔진 전체. 풀이 봇은 "작가 해법 재생 + 도달 가능성"부터.
4. **2쪽짜리 "핵심 계약" 문서**(조작, 당기기 공식, 잠금, 조합표)를 따로 만들어 에이전트 기준으로 삼고, 세부 수치는 튜닝 데이터 파일로 분리. 남은 작은 모순 6개 정리.
5. **오너 결정 필요**: 주당 투입 가능 시간, 최소 수용 순수익 선, 스팀덱 보유 여부, 2028년 4월 출시 수용 여부(아니면 축소안 ① 선적용), 영상 6편 제목·메모, 영문 제목 후보 상표 조회.
