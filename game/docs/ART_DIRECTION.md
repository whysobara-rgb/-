# 아트·연출 방향 — "장난감 상자 속 한밤의 털이"

목표 감성: 닌텐도 계열 파티·액션 게임이 주는 **장난감 같은 질감, 모든 것이 반응하는 세계,
기분 좋은 피드백**. 단, 특정 회사·작품의 캐릭터·로고·폰트·음악·사운드·아이템 디자인을
**절대 모방하지 않는다**. 가져오는 것은 일반적인 디자인 원칙뿐이다.

## 1. 핵심 원칙

| 원칙 | 구체적인 적용 |
|---|---|
| 장난감 같은 재질 | 말랑한 플라스틱·점토 느낌의 툰 셰이딩, 둥근 모서리, 굵은 실루엣, 때·녹·피 없음 |
| 선명한 색 언어 | 채도 높은 파스텔 + 강한 명암 대비. 상호작용 대상은 윤곽선과 그림자로 즉시 구분 |
| 모든 것이 반응 | 지나가면 꽃·풀이 흔들리고, 은행이 지나가면 가로등·간판이 흔들리며, 비둘기가 날아오름 |
| 애니메이션 12원칙 | 예비 동작 → 동작 → 여운. 눌림·늘어남, 오버슈트, 꼬리·귀의 지연 흔들림 |
| 층층이 쌓인 피드백 | 모든 행동에 화면 + 소리 + 진동이 함께. 큰 사건일수록 층이 많아짐 |
| 음악적인 효과음 | 효과음을 현재 곡의 조성에 맞춤. 연속 회수 시 동전 소리가 한 음씩 올라감 |
| 해보면서 배우기 | 긴 설명 대신 짧은 문장 + 행동 아이콘 + 하이라이트 |
| 친절한 카메라 | 플레이어와 싸우지 않는 부드러운 추적, 큰 순간에만 짧고 강한 연출 |
| 통통 튀는 UI | 큰 글씨, 둥근 버튼, 오버슈트 이징(back/elastic), 도형 와이프 전환, 음악적인 메뉴음 |

## 2. 손맛(게임 필) 규칙

- **히트스톱**: 돌진 명중 약 70ms, 은행 뽑힘 약 120ms, 은행 회수 약 150ms 동안 시뮬레이션을 멈춘다.
  판정은 그대로이고 체감 시간만 바뀐다.
- **카메라 펀치**: 충격 방향으로 짧게 밀렸다가 탄성 있게 복귀한다. 큰 회수에서는 짧게 줌인한다.
- **임팩트 프레임**: 넉다운 순간 1~2프레임 동안 흰 실루엣 플래시와 방사형 선을 보여준다.
- **눌림·늘어남**: 돌진 출발 시 늘어나고, 충돌·착지 시 눌린다. 금고를 잡는 순간 손이 "딱" 붙는다.
- **점수 연출**: 숫자가 롤업되고, 동전이 쏟아지고, 값에 비례해 화면과 소리가 커진다.
  은행째 회수는 최대 연출 — 건물 500 + 금고 N이 순서대로 쌓이는 합산 팝업.
- **진동**: 잡기 가벼운 틱, 넉다운 묵직한 쿵, 은행 뽑힘·회수 긴 웅웅.
- 모든 강한 연출은 설정의 화면 흔들림 / 움직임 줄이기 / 진동 옵션을 따른다.

## 3. 저작권·상표 회피 체크리스트

- 다른 게임의 캐릭터, 이름, 로고, 아이콘, UI 레이아웃을 그대로 쓰지 않는다.
- 상업 폰트를 쓰지 않는다. 쓰는 폰트는 OFL 라이선스인 Jua와 Noto Sans KR뿐이다.
- 기존 게임 음악·징글·효과음의 멜로디나 리듬을 재현하지 않는다. 모든 음악과 효과음은 절차적으로 새로 만든다.
- 오해를 부르는 상징물을 피한다. 버섯 파워업, 물음표 블록, 눈 달린 별, 나뭇잎 마크, 잉크 튀김 같은 특정 작품의 상징을 넣지 않는다.
- 동전 디자인은 독자적으로 만든다. 너구리 발자국 각인 + 둥근 테두리로, 세로 홈 있는 금색 타원 같은 다른 작품의 모양은 쓰지 않는다.
- 팀 문양(별·달)은 일반적인 기하 도형으로만 그린다.
- 상점 이름·간판은 모두 가상의 이름이다. 실제 브랜드 이름을 쓰지 않는다.
- 상점 페이지와 홍보물에 다른 회사·작품 이름을 비교 마케팅으로 쓰지 않는다. 기획서 §15의 비교는 내부 문서에만 둔다.
